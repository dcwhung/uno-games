Events 出口Toasts 讀 7 種 event；scene 唔讀 events 只讀 stateToasts.tsx:11-24

重要設計決定

  • Engine 零 side effect：seed 由 app 產生，engine 只用 rngForTick。Replay 可 byte-for-byte 重現（已由 spec 驗證）。
  • Bots 只收 PublicView：botDriver.ts:40-42 係唯一 call site，先 getPublicView 再傳入。
  • Events 帶 seq：消費者（Toasts）用 lastSeq idempotent 處理，避免 re-render 重複 toast。
  • Gap：event-sourced 架構嘅主要回報（reload 續局、bug 重現）而家攞唔到，因為 actionLog 只寫唔存（AU-009）。
